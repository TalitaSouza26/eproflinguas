# Figuras da trilha "Casa e família"

Uma por palavra, com **exatamente** estes nomes de arquivo — o código monta o
caminho a partir da palavra:

| Arquivo | Palavra | Português |
| --- | --- | --- |
| `mother.webp` | Mother | mãe |
| `father.webp` | Father | pai |
| `sister.webp` | Sister | irmã |
| `brother.webp` | Brother | irmão |
| `family.webp` | Family | família |
| `garden.webp` | Garden | quintal |
| `baby.webp` | Baby | bebê |
| `kitchen.webp` | Kitchen | cozinha |
| `bedroom.webp` | Bedroom | quarto |
| `door.webp` | Door | porta |
| `window.webp` | Window | janela |
| `bed.webp` | Bed | cama |
| `table.webp` | Table | mesa |
| `chair.webp` | Chair | cadeira |
| `sofa.webp` | Sofa | sofá |

`House` usa a figura que já existe em `public/quiz/house.webp`.

Enquanto o arquivo não existir, a tela mostra uma moldura tracejada dizendo
qual desenho falta — nada quebra.

Quadradas, fundo transparente ou claro, o objeto centralizado e sozinho: a
figura é a definição da palavra, então nada de cena com várias coisas em que a
criança não saiba qual delas é a resposta.
